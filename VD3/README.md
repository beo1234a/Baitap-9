# shop-springboot-4-1-1
Spring Boot + Security + Thymeleaf + SQL Server + MapStruct + Mail + Cloudinary.

1. Tao database webst3.
2. Copy .env.example thanh .env va dien thong tin SQL Server/Gmail/Cloudinary.
3. Maven Update Project.
4. Run ShopApplication.
5. Mo http://localhost:8080.

Tai khoan demo: admin / 123456 (ADMIN), user / 123456 (USER).
Chuc nang: Register OTP, Verify/Resend OTP, Login session, Logout, Forgot/Reset password, CRUD/Search/Pagination User, Role, dem User/Product, CRUD/Search/Pagination Product, Cloudinary, MapStruct.
